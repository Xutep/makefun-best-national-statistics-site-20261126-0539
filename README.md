Arunaya National Statistics — the official statistics site of the fictional Republic of Arunaya: population, economy, prices, jobs, trade and regions, with real figures in place, sources and years on every number, and charts drawn as SVG from the site's own data files. Six pages on hash routes, sortable and filterable tables, indicator tabs, a phone layout, and no network request at all.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` in a browser directly.
